# Okoscope Adopters

This file records organizations that have agreed to be publicly identified as
Okoscope adopters. It is intentionally empty until an adopter grants permission;
GitHub stars, downloads, evaluations, and maintainers' own deployments are not
presented as independent adoption.

To be listed, open a pull request adding one row:

| Organization | Industry | Usage | Environment | Public reference |
| --- | --- | --- | --- | --- |
| _Example (remove this row)_ | _Industry_ | _What Okoscope supports_ | _Evaluation or production_ | _Optional case study or contact-approved link_ |

An organization may omit sensitive implementation details. Maintainers may ask
for a private contact who can verify the entry. CNCF adopter interviews and
private references are handled separately and are never published without
permission.
