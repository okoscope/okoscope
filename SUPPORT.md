# Support

Okoscope is maintained by its open-source community and currently has no
guaranteed response or resolution times.

| Need | Channel |
| --- | --- |
| Usage question or troubleshooting | [Support question](https://github.com/okoscope/okoscope/issues/new?template=question.yml) |
| Reproducible defect | [Bug report](https://github.com/okoscope/okoscope/issues/new?template=bug_report.yml) |
| Feature or design proposal | [Feature request](https://github.com/okoscope/okoscope/issues/new?template=feature_request.yml) |
| Security vulnerability | Private process in [SECURITY.md](SECURITY.md) |
| Code of Conduct concern | Private process in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Before requesting help, review the [installation guide](docs/installation.md),
[platform support](docs/platform-support.md), and
[production operations guide](docs/self-hosted-deployment.md). Include versions,
deployment method, relevant redacted configuration, expected behavior, actual
behavior, and minimal reproduction steps.

Never post credentials, authentication tokens, private keys, personal data, or
unredacted production logs.
